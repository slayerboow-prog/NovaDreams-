# Capturas de movimiento

`backflip.json`: CMU Graphics Lab Motion Capture Database (http://mocap.cs.cmu.edu), sujeto 88,
toma 01 (backflip). The data used in this project was obtained from mocap.cs.cmu.edu. The database
was created with funding from NSF EIA-0196217. Uso libre, también en productos comerciales.
Convertido al esqueleto del juego con `tools/mocap/cmu_to_clip.py`.
